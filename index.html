The problem

  • Agents built earlier were only emailing one match per lead and re-sending to the same people, causing bounces and spam flags.
  • The client wanted a proper SDR sequence, not accidental duplicate sends.

What I built

  • Rebuilt the agents with array extraction + iterators so every profile is processed once.
  • Daily follow-up sweep, reply listeners that log responses back to the lead sheet, and a Calendly booking listener.
  • A new Realtor SDR agent sending through pre-warmed Instantly inboxes, plus two recruitment agents cloned from it.
